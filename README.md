# granger-causal-multimorbidity-networks

Code accompanying the paper

> **Granger-causal relationships in cardiometabolic disease progression networks from longitudinal health records**
> N. Fontana, A. D. Haue, E. Di Angelantonio, P. Secchi, S. Brunak, F. Ieva (submitted).

Directed disease-to-disease networks are estimated from longitudinal clinical
event sequences with multivariate Hawkes point processes and sparse-group-lasso
regularised maximum likelihood (MLE-SGL), interpreted under a Granger-causality
framework. Edges are predictive, temporally ordered relationships; they are not
estimates of counterfactual or interventional causal effects.

## Data availability

The analyses used the Danish National Patient Register and UK Biobank. These
data cannot be shared and are not included. The repository contains synthetic
data with the same structure as the real input (`data/synthetic/`,
`data/synthetic_replication/`; see [docs/data_format.md](docs/data_format.md)),
generated by `synthetic/generate_synthetic_data.R` from a random network. Results
on synthetic data are not expected to reproduce the paper's estimates.

## Requirements

- MATLAB (tested with R2023a) with the Statistics and Machine Learning Toolbox
- R (≥ 4.3) with `data.table`, `jsonlite`, `ggplot2`, `igraph`, `ggraph`,
  `patchwork`, `R.matlab`, `rmarkdown`, `knitr`; pandoc (bundled with RStudio)
- `bash`, `curl`, `tar`, `patch`

## Quick start

```bash
bash setup/install_toolkit.sh     # download the Hawkes-Process-Toolkit and apply our patch
bash run_pipeline.sh              # full pipeline on the synthetic data (~3 min)
```

If `matlab` is not on the PATH: `MATLAB=/path/to/matlab bash run_pipeline.sh`.
The HTML reports are written to `results/reports/`.

## Pipeline

| Step | Code | Output |
|---|---|---|
| 1. Event tables → sequences and cohorts | `R/01_build_sequences.R` | `results/sequences/<analysis>/` |
| 2a. Selection of the penalties (validation BIC) | `matlab/pipeline/run_grid_search.m` | `results/grid_search/` |
| 2b. Network estimation (MLE-SGL Hawkes) | `matlab/pipeline/run_estimation.m` (all analyses: `matlab/run_all_estimations.m`) | `results/models/<analysis>/` |
| 3. Analysis reports | `R/03_render_reports.R` with `reports/*.Rmd`, functions in `R/analysis_functions.R` | `results/reports/` |
| Simulation studies | `matlab/run_simulations.m` with `'smoke'`, `'paper'` (Supplementary Methods S2), `'nd_sweep'` (N × D), `'misspec'` (kernel-basis misspecification) | `results/simulations/<set>/` |

Settings (study design, analyses, estimation, grid search) are in
[config/settings.json](config/settings.json). The analyses are:

| Analysis | Events modelled | Cohort |
|---|---|---|
| `baseline` | 29 CMD | ≥3 CMD events |
| `risk_adjusted` | 29 CMD + 38 RISK | ≥3 CMD events |
| `extended` | 29 CMD + 38 RISK | ≥3 CMD or RISK events |
| `baseline_women`, `baseline_men` | 29 CMD | primary cohort split by sex |

The `paper`, `nd_sweep` and `misspec` simulation sets use up to N = 500,000
sequences and need an HPC cluster; `smoke` and `misspec_smoke` run in a few
minutes on a laptop. Completed scenarios are skipped, so runs can be resumed.

The replication analysis is the `baseline` analysis applied to a second dataset
(`data/synthetic_replication/`, generated from the same synthetic network).
See [docs/reproducing_the_paper.md](docs/reproducing_the_paper.md) for the
correspondence between the paper and the code.

## Hawkes-Process-Toolkit

Estimation relies on the MLE-SGL implementation of the
[Hawkes-Process-Toolkit](https://github.com/HongtengXu/Hawkes-Process-Toolkit)
by Hongteng Xu (Xu, Farajtabar & Zha, *Learning Granger causality for Hawkes
processes*, ICML 2016). The toolkit is not redistributed here:
`setup/install_toolkit.sh` downloads it at commit `2548a41` and applies one
patch (`setup/patches/thap_empty_sequence_guard.patch`), which lets the
simulator return sequences without events instead of failing. Estimation code
is used unmodified. Please cite the toolkit's papers as well as ours.

## Repository structure

```
config/       settings.json: study design, analyses, estimation and grid search
data/         event definitions (29 CMD + 38 RISK) and synthetic datasets
docs/         input format, correspondence with the paper
matlab/       estimation pipeline, simulation study, project Hawkes utilities
R/            sequence building, analysis functions, report rendering
reports/      R Markdown reports (single network, network comparison)
setup/        toolkit installation and patch
synthetic/    synthetic data generator
```
